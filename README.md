

## How to use?

First we are going to have to enable CSS tinkering in firefox:
  
1. Open Firefox and type in the address bar: about:config

2. Accept the “Proceed with caution” warning.
   
3. Search for this preference: toolkit.legacyUserProfileCustomizations.stylesheets

4. Set it to true

 Now you need to locate the firefox root folder and you can do so by following these steps:

 1. In Firefox’s address bar, go to: about:support
 2. Under Application Basics, find Profile Folder
 3. Click Open Folder (this opens your active profile directory).
 4. Inside your profile folder simply place the chrome folder inside and restart your firefox
 5. Now restart firefox and the theme should be working :)
